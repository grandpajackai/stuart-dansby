# Taking the Fight v2 (elevated preview)
Preview pages: `/v2/` (corporate speaking), `/v2/education/`, `/v2/course/`. Marked `noindex` until approved.
Settings live in `v2/config.js`: BOOKING_URL (discovery-call link; empty = pre-written email), COURSE_PRICE (empty = hidden), COURSE_CHECKOUT_URL (empty = early-access only).
Forms open a pre-filled email to info@takingthefight.com until a form service is connected.
Pages are generated by `_tools/build.py` (edit there, then run it); `_tools/qa.py` is the Playwright QA pass.
